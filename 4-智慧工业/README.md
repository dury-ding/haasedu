# 智慧工业
&emsp;&emsp;
18世纪，英国人瓦特发明了蒸汽机，引发了第一次工业革命，开创了以机器代替手工工具的时代。人类从此进入了工业时代。1870年以后，科学技术的发展突飞猛进，各种新技术、新发明层出不穷，并被迅速应用于工业生产，大大促进了经济的发展。这就是第二次工业革命。<sup>[1]<sup>

&emsp;&emsp;
进入21世纪以后，随着科技的发展，以及物联网的发展，智能化成为了科技发展的趋势。工业作为社会经济的一大主体，推动着社会的进步，其科技的发展也朝智能化的方向发展。<sup>[1]<sup>

&emsp;&emsp;
智能工业的实现是基于物联网技术的渗透和应用，并与未来先进制造技术相结合，形成新的智能化的制造体系。所以，智能工业的关键技术在于物联网技术。<sup>[1]<sup>

&emsp;&emsp;
物联网的泛在感知网络技术、泛在制造信息处理技术、虚拟现实技术、人机交互技术、空间协同技术、平行管理技术、电子商务技术及系统集成制造等技术在制造业供应链管理、生产过程工艺优化、产品设备监控管理、环保监测及能源管理、工业安全生产管理等智慧工业的方方面面都有很广泛的应用前景。
