# 智能生活
&emsp;&emsp;
随着近些年智能音箱逐渐走进老百姓的日常生活，围绕智能音箱的各种智能电器设备也逐渐开始普及。大家的日常生活中也有非常多的案例，比如我们可以通过语音或者App来控制各种灯的开关。也可以在回家前就通过App远程开启家里的空调，到家之后不用再等立马就可以很舒适。我们在离开家之后，可以开启智能摄像头的监控功能，监控到可疑人员之后自动报警，守护家庭的安全。有了智能门锁，我们出门就不用带钥匙了，再想象一个场景，如果你临时出门了，但有个朋友来拜访，在没有智能门锁之前就得让朋友在外面等着，有了智能门锁，我们可以做到给朋友远程开门。有了智能灯带，晚上在睡觉前可以将等待设置为自动模式，这样我们晚上下床之后等待可以自动开启，避免在黑暗中发生事故；在厨房中增加火焰或燃气传感器之后，一旦发现燃气泄露或者厨房着火的情况出现，我们也可以第一时间发现处理。
