# 番茄工作法

&emsp;&emsp;
番茄工作法是一种可以有效管理时间的工具，在平时的工作学习中经常会被各种所谓的“事情”（抽根烟、吃点零食、说悄悄话等等）给打断，极大降低工作学习的效率。有了番茄工作法，我们可以在规定的番茄时间内专注于做一件事情，中途不能再做与该事情无关的事，直到番茄时间结束，然后就在系统中给这件事记录一个番茄。番茄工作法可以非常有效地提高工作学习效率，同时也可能会有意想不到的收获。

&emsp;&emsp;
本章课程主要介绍如何手把手打造一个番茄工作法的系统。主要包含以下几部分的内容。
* 背景知识
* 功能场景拆解
* 硬件说明
* 实验步骤详解
* 课后作业

## 背景知识

&emsp;&emsp;
本章课程打造的番茄工作法是一个番茄时间25分钟，可以通过按键停止或启动番茄时间，每个番茄时间结束，就上报一个番茄到云端或本地记录。

<br>

## 功能场景拆解

&emsp;&emsp;
本章课程设计的番茄工作法，涉及到HaaS EDU K1上集成的OLED屏显示、按键等硬件单元，场景设计的行为如下：
1. 通过OLED显示番茄时间倒计时
2. 按键切换番茄时钟的启动和暂停
3. 将番茄数保存在本地或上报云端

<br>

## 硬件说明

&emsp;&emsp;
番茄时钟案例使用的硬件HaaS EDU K1上集成的OLED、按键硬件单元，无需外围扩展连接。


&emsp;&emsp;
实验整体步骤如下：
1. 设计一个倒计时功能，并且在OLED屏幕上显示
2. 完成一次番茄时钟，系统记录一个番茄数，并且上报云端
3. 可以通过按键触发启动或暂停番茄时钟

<br>
