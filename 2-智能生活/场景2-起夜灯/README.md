# 起夜灯

&emsp;&emsp;
起夜灯是生活中非常常见的一种小型智能设备，他实现的功能就是当夜晚人经过的时候，灯光亮起；当人离开后一段时间，灯光就会自动熄灭。起夜灯主要是通过感应人体的传感器来实现的人体经过的检测的。

## 起夜灯原理

&emsp;&emsp;
**红外线**是一种人类肉眼看不到的光，虽然看不见，但他有一个显著的特性就是具有热效应，即所有高于绝对零度的物质都会产生红外线。人体热释电红外传感器就是一种能探测人体红外光谱变化的传感器，他能检测人发射的红外线，并转化为电信号输出。

&emsp;&emsp;
使用一个控制器来接收人体热释电红外传感器的信号，通过这个信号来控制灯的开启和关闭，就可以制作一个实用的起夜灯。

## 场景功能拆解
本场景中主要分为人体检测，灯控制及数据上云三部分，各部分功能如下。
1. 人体检测：检测环境中是否有人经过
2. 灯控制：当检测到人的时候，打开灯；人离开后，关闭灯
3. 数据上云：当前起夜灯的状态数据上报到云平台

## 课后作业
本场景中通过检测是否有人体活动作为点亮小夜灯(LED)的唯一判断依据，请在原系统的基础上：
* 加入定时器功能，按照每天白天的时间段自动关闭小夜灯功能；夜晚的时间段自动开启小夜灯功能。
* 加入光强度传感器来自动判断室内光亮度是否足够，如果亮度过暗则开启小夜灯；否则不用开启小夜灯。
* 统计人每天起夜的次数，并生成实时曲线通过web或移动端app的方式进行查看（对于老人来说，如果出现企业次数增多的情况可能是身体某些部位出现病变的信号）。
