# 常见外设接口介绍

&emsp;&emsp;
物联网设备经常会需要用到外部的传感器来感知物理世界的物理信息或通过显示设备来和用户进行交互，那这些外部的设备和微处理器是怎样连接起来的呢？
本节就主要介绍常用微处理器在和外部元器件或设备进行通信的时候采用的接口形式。主要覆盖以下几种类型的接口：
* [UART](./常见外设接口介绍.md "UART")
* [GPIO](./常见外设接口介绍.md "GPIO")
* [ADC](./常见外设接口介绍.md "ADC")
* [DAC](./常见外设接口介绍.md "DAC")
* [PWM](./常见外设接口介绍.md "PWM")
* [I2C](./常见外设接口介绍.md "I2C")
* [SPI](./常见外设接口介绍.md "SPI")

<br>

## UART
&emsp;&emsp;
UART是通用异步收发传输器（Universal Asynchronous Receiver/Transmitter）的缩写。它是一种通用串行数据总线，用于异步通信。该总线双向通信，可以实现全双工传输和接收。UART常用于主机与辅助设备通信，如微处理器和外接RFID模块或外接LoRa/NB-IoT等模块之间的通信。
UART工作原理是将要传输数据的每个字符一位接一位地传输，如下图所示：

&emsp;&emsp;
上图中各个数据位的意义说明如下：
* 起始位  
先发出一个逻辑”0”的信号，表示传输字符的开始。

* 数据位  
紧接着起始位之后。数据位的个数可以是4、5、6、7、8等，构成一个字节。通常采用ASCII码。从最低位开始传送，靠时钟定位，上图为8个bit一个字节（内容为0x55）的传输过程。

* 奇偶校验位  
资料位加上这一位后，使得“1”的位数应为偶数（偶校验）或奇数（奇校验），以此来校验资料传送的正确性。示意图中采用的是奇校验的方式。

* 停止位  
它是一个字符数据的结束标志。可以是1位、1.5位、2位的高电平。 由于数据是在传输线上定时的，并且每一个设备有其自己的时钟，很可能在通信中两台设备间出现了小小的不同步。因此停止位不仅仅是表示传输的结束，并且提供计算机校正时钟同步的机会。适用于停止位的位数越多，不同时钟同步的容忍程度越大，但是数据传输率同时也越慢。

* 空闲位  
处于逻辑“1”状态，表示当前线路上没有数据传送。

* 波特率  
波特率是UART使用过程中最重要的指标之一，它是衡量资料传送速率的指标，表示每秒钟可以传送的比特数，每8bit数据位代表一个字节。现代微处理器一般最常使用的波特率有115200、921600等，高速UART可以达到1500000、3000000、4000000等。

> 在数据位为8bit、关闭奇偶校验、停止位为1bit的情况下，采用115200的波特率，每秒可以传输的字符数量计算方法为：115200/（1起始位+8数据位+1停止位+1空闲位），约为10472字节。
> 
> 平时我们还会听到RS232、RS485等名词，它们其实是两种不同的电器特性协议，它们对传输在数据通路上的信号的电气特性及物理特性进行了定义 ，属于物理层传输规范，它们并没有对传输在上面的数据传输格式进行定义。

## GPIO
&emsp;&emsp;
GPIO是通用型输入输出（General-purpose input/output）的简称，其引脚可以供使用者由程控自由使用，GPIO可作为通用输入（GPI）或通用输出（GPO）的功能选择。GPIO可以对外输出或读取外部输入的数字信号（即只有0和1两种状态）。GPIO单独作为输出功能使用时常用于开关量的控制，比如控制灯的开关、风扇开关、插座的是否对外输出电压等等；单独作为输入功能则常用于获取物体的运行状态、比如设备是否处于上电状态、传感器是否检测到有效信号等等。GPIO除单独使用之外，还常和其它的总线一起工作完成更复杂的功能。比如SPI协议中的CS（chip select，片选信号）就是用GPIO功能来选择当前要通信的SPI从设备。
> GPIO在开发板上一般是通过引脚的方式提供给开发者使用，开发过程中通常是使用杜邦线和外部元件的引脚连接。

<br>

# ADC
&emsp;&emsp;
ADC即模拟数字转换器（Analog-to-Digital converter）是用于将模拟形式的连续信号转换为数字形式的离散信号的一类设备。与之相对的设备为数字模拟转换器（DAC）。
典型的模拟数字转换器将模拟信号转换为表示一定比例电压值的数字信号。一个完整的ADC过程分为采样、保持、量化和编码四个步骤。前两个步骤在采样-保持电路中完成，后两步骤则在ADC中完成。常用的ADC有积分型、逐次逼近型、并行比较型/串并行型、Σ -Δ调制型、电容阵列逐次比较型及压频变换型。

&emsp;&emsp;
ADC的主要技术指标如下：
* 分辨率  
指输出数字量变化一个最低有效位（LSB）所需的输入模拟的变化值。

* 精度  
精度决定于量化误差及系统内其他误差之总和。一般精度指标为满量程的百分比，如一般精度指标为满量程的±0. 02% ，高精度指标为满量程的0.001%。

* 转换速率  
指完成一次从模拟转换到数字的AD转换（从模拟信号想数字信号的转换）所需的时间的倒数。

* 量化误差  
量化误差因为ADC的有限分辨率而引起的误差，通常是1个或半个最小数字量代表的模拟量大小，表示为1LSB、1/2LSB。

>自电子管ADC面世以来,经历了分立半导体、集成电路数据转换器的发展历程。ADC转换速度、转换精度及集成度方面等主要指标上有了重大突破。除了ADC自身的指标外，物联网领域使用的ADC期间还会集成和MCU通信的通信接口，更加方便的被操作系统及应用程序集成使用，大大拓展了其使用范围。在物联网的感知层中，传感器是最重要的组成部分，非常大量的传感器中都需要使用到ADC技术对物理世界的模拟量转化成MCU可以识别的数字量。可以说，ADC技术是物联网产业的基础输入（测量）技术之一。

<br>

## DAC
&emsp;&emsp;
DAC即数字模拟转换器（英语：Digital-to-Analog converter）是用于将数字形式的离散信号转换为模拟形式的连续信号的一类设备。
一般按输出是电流还是电压、能否作乘法运算等进行分类。大多数DAC由电阻阵列和n个电流开关（或电压开关）构成。按数字输入值切换开关，产生比例于输入的电流（或电压） 。此外，也有为了改善精度而把恒流源放入器件内部的。DAC分为电压型和电流型两大类，电压型DAC可分为权电阻网络、T型电阻网络和树形开关网络等；电流型DAC可分为权电流型电阻网络和倒T型电阻网络等。

&emsp;&emsp;
DAC的主要技术指标如下：
* 分辨率  
输出模拟电压的最小增量，即表明DAC输入一个最低有效位（LSB）而在输出端上引起的模拟电压的变化量。

* 转换时间  
将一个数字量转换为稳定模拟信号所需的时间，常用建立时间来描述此转换速度。一般情况下，电流型DAC转换时间较短，电压型DAC转换时间较长。

* 精度  
在输入端加有最大数值量时，DAC的实际输出值和理论计算值之差，它主要包括非线性误差、比例系统误差、失调误差等。

* 线性度  
在理想情况下，DAC的数字输入量作等量增加时其模拟输出电压也应作等量增加，但是实际输出往往有偏离。

> 随着通信行业、多媒体技术和数字化设备的飞速发展，信号处理越来越趋向数字化，促进了高速DAC有了长足进步，牵动着DAC制造商研制出许多新结构、新工艺及各种特殊用途的高速DAC。物理世界中大多数设备端的运行都是采用模拟信号的方式进行控制，如果要是用微控制器(MCU)对其进行控制，则一定需要经过DAC转换成设备可以识别的模拟信号才可以。可以说，DAC技术是物联网产业的基础输出（控制）技术之一。

<br>

## PWM
&emsp;&emsp;
PWM（Pulse Width Modulation）是脉冲宽度调制技术的缩写。它是利用微控制器的数字输出来对模拟电路进行控制的另外一种非常有效的技术，广泛应用在从测量、通信到功率控制与变换的许多领域中。它有两个非常重要的参数：频率和占空比。
* 频率和周期是互为倒数的
* 占空比是指一个周期内高电平所占的比例

&emsp;&emsp;
PWM信号就是根据需求调节占空比的大小以实现负载端电压的线性变化，如下图所示,图中高电平电压为5V，占空比在50%的情况下，相当于对外输出2.5V的等效电压；占空比在75%的情况下，相当于对外输出3.75V等效电压。

## I2C
&emsp;&emsp;
I2C，正确的读法是I方C。它的英文全称是Inter-Integrate Circuit，是一种串行通信总线，使用的是多主从架构，由飞利浦公司在80年代为了让CPU能够连接低速外设而设计的。目前I2C的规范已经到了6.0版本。

&emsp;&emsp;
I2C应用场景很多，最常见的场景如下：
* 保护用户设置常用的NVRAM芯片
* DAC和ADC，实现数字信号和模拟信号之间的相互转换
* 小型的液晶屏或者OLED屏，这种屏分辨率不能太高
* 各种监控模块，比如手机上的电池监控、键盘监控、CPU温度和风扇转速监控模块等
* 实时时钟芯片
* GPIO扩展芯片
* 各种传感器，像温湿度传感器、光强度传感器、加速度传感器、陀螺仪传感器、接近传感器等

<div align="center">
<img src=./../../图片/ext_I2C设备接线示意图.png width=80%/>
</div>

&emsp;&emsp;
常见I2C总线连线结构图如图上图所示，主要特点如下：

* 由SC和SDA两条双向漏极电路组成，需要外接上拉电阻才能正常工作
* 基于地址的数据传输，总线上挂在的每个I2C从设备由唯一的一个地址标识，就像IP地址一样。I2C的地址模式有两种，早期的I2C设备只有7-bit地址模式，后来扩展到了10-bit地址模式
* 支持多主模式，也就是说同一条I2C总线上，可以连接多个主设备也可以连接多个从设备
* 半双工，同一时刻，要么主设备向从设备发送数据，要么从设备向主设备发送数据，数据传输不能双向同时进行
* 支持多种速度模式，10k及以下成为低速模式，标准速度是100kbps，快速模式是400kbps，快速plus模式是1+Mbps，高速模式是3.4+Mbps，现在还有超高速模式可以达到5Mbps

&emsp;&emsp;
影响I2C速度的因素主要是I2C信号跳变到稳定状态所花费的时间，大家都知道数字信号只有0和1，但是信号在发生0和1切换的时候是需要一个转换时间的，这个转换时间跟接上图中的电容大小有关。转换时间时间越短，I2C的速度就可以越快。下表是I2C在标准模式、快速模式及快速plus模式下对信号稳定时间及外界电容大小的要求。

| 速度模式 | 标准模式 | 快速模式 | 快速+模式 |
| :-: | :- |  :- |  :-  |
| 最大速度值 | 100kbps |  400kbps |  1Mbps  |
| 最大电容值 | 400pF |  400pF |  550pF  |			
| 转换时间 | 1000ns |  300ns |  100ns  |

## SPI
&emsp;&emsp;
SPI（Serial Peripheral Interface） 串行外围设备接口，是Motorola公司推出的一种同步串行接口技术。它是一种高速、全双工、同步的通信总线，既有I2C多设备通信的优点，又支持像串口那样的全双工通信，而且时钟频率高。  

&emsp;&emsp;
SPI类型外设和开发板连接至少需要占用6个引脚，包括：
* GND - 电源地线
* VCC - 电源正极
* CS - 从设备使能信号引脚（由主设备MCU控制）
* SCK - 同步数据传输的时钟线
* MOSI - 主设备输出从设备输入
* MISO - 主设备输入从设备输出

&emsp;&emsp;
CPOL与CPHA是SPI中非常重要的概念，其分别代表SPI的时钟极性（Clock Polarity）和时钟相位（Clock Phase）。CPOL和CPHA分别都可以是0或1，对应的四种组合如下表所示。

| 模式 | 极性、相位取值 |
| :-: | :- |
| Mode 0 | CPOL= 0，CPHA = 0 |
| Mode 1 | CPOL = 0，CPHA = 1 |
| Mode 2 | CPOL = 1，CPHA = 0 |
| Mode 3 | CPOL = 1，CPHA = 1 |

&emsp;&emsp;
了解CPOL之前，需要先了解什么是时钟空闲时刻，字面理解就是此时时钟此时处于稳定状态，与此对应的，时钟在发送数据的时候，就是正常的工作的时候了。
SPI的CPOL表示当时钟空闲的时候，其电平的值是低电平0还是高电平1。如下图所示：

<div align="center">
<img src=./../../图片/ext_CPOL示意图.png width=80%/>
</div>

&emsp;&emsp;
CPOL=0，时钟空闲idle时候的电平是低电平，所以当SCLK有效的时候，就是高电平，这就是高有效。

&emsp;&emsp;
CPOL=1，时钟空闲idle时候的电平是高电平，所以当SCLK有效的时候，就是低电平，这就是低有效。

&emsp;&emsp;
CPHA相位，对应着数据采样是在第几个边沿（edge），是第一个边沿还是第二个边沿，0对应着第一个边沿，1对应着第二个边沿。如下图所示：
<div align="center">
<img src=./../../图片/ext_SPI数据传输示意图.png width=80%/>
</div>

&emsp;&emsp;
CPHA=0，表示第一个边沿：  
* 对于CPOL=0，idle时候的是低电平，第一个边沿就是从低变到高，所以是上升沿；  
* 对于CPOL=1，idle时候的是高电平，第一个边沿就是从高变到低，所以是下降沿；

&emsp;&emsp;
CPHA=1，表示第二个边沿：  
* 对于CPOL=0，idle时候的是低电平，第二个边沿就是从高变到低，所以是下降沿；  
* 对于CPOL=1，idle时候的是高电平，第一个边沿就是从低变到高，所以是上升沿。

> SPI主要应用在 EEPROM、Flash、 实时时钟（RTC）、数模转换器（ADC）、 数字信号处理器（DSP）以及数字信号解码器之间。
