## 三、软件接口
<br>

### MLX90614(i2cObj) - 创建MLX90614驱动对象
<br>

* 函数原型

> mlx90614Obj = MLX90614(i2cObj)

* 参数说明

参数|类型|必选参数？|说明|
|:-:|:-:|:-:|:-|
|i2cObj|I2C|是|调用此函数前需确保i2cObj对象已经处于open状态|

* 返回值

> MLX90614对象成功，返回MLX90614对象；MLX90614对象创建失败，抛出Exception

* 示例代码
```python
import utime
import mlx90614
from driver import I2C    # 驱动库

i2cObj = I2C()

i2cObj.open("mlx90614")
print("mlx90614 inited!")

mlx90614Dev = mlx90614.MLX90614(i2cObj)   # 初始化mlx90614传感器
```

* 输出
```python
mlx90614 inited!
```
</br>

### read_object_temp() - 获取人体的温度
<br>

* 函数功能：

> 获取人体的温度 

* 函数原型： 

> MLX90614.read_object_temp()

* 参数说明：

> 无

* 返回值：

> 测量的人体温度

* 示例：

```python
import utime
import mlx90614
from driver import I2C    # 驱动库

i2cObj = I2C()

i2cObj.open("mlx90614")
print("mlx90614 inited!")

mlx90614Dev = mlx90614.MLX90614(i2cObj)   # 初始化mlx90614传感器

print('read temp: %0.2f'%mlx90614Dev.read_object_temp())
```

* 输出
```python
mlx90614 inited!
read temp: 33.24
```

* 函数功能：

* 参数说明：

## 四、接口案例

此使用实例在board.json中定义了名为MLX90614的I2C类型的对象。在Python脚本中读取测量的周围环境温度和人体的温度并打印在日志中。

* 案例代码
```python
{
    "name": "esp32",
    "version": "1.0.0",
    "io": {
      "mlx90614": {
        "type": "I2C",
        "port": 0,
        "addrWidth": 7,
        "freq": 50000,
        "mode": "master",
        "devAddr": 90
      }
    },
    "debugLevel": "ERROR",
    "repl": "disable"
}
```

```python
import utime
import mlx90614
from driver import I2C    # 驱动库

i2cObj = I2C()

i2cObj.open("mlx90614")
print("mlx90614 inited!")

mlx90614Dev = mlx90614.MLX90614(i2cObj)   # 初始化mlx90614传感器

while True:
    object_temp = mlx90614Dev.read_object_temp()
    ambient_temp = mlx90614Dev.read_ambient_temp()
    print("{0:>5.2f}C | {1:>5.2f}C".format(ambient_temp, object_temp), end='\r')
    print("\r")
    utime.sleep_ms(500)
```

* 输出
```python
mlx90614 inited!
23.68C | 33.39C
23.21C | 33.12C
23.49C | 33.83C
```
