# 温湿度传感器 - SI7006

## 一、产品简介
Si7006是Silicon Labs出品的温度及湿度传感器，它集成了温湿度测量元件、信号处理电路及模数转换器。温度和湿度传感器由工厂校准，校准数据存储在片上非易失性存储器中。这可确保传感器完全可互换，无需重新校准或软件更改。Si7006提供精确、低功耗、工厂校准的数字解决方案，非常适合测量湿度、露点和温度，在远程遥测装置、智能手机、气象站等场景有广泛应用。

## 二、技术参数
* 供电电压：1.9~3.6V
* 采用I2C通信协议，最高传输速率可到400KHz，I2C地址是0X40
* 温度测量范围： -10°C至+ 85°C，最大误差为±1.0℃
* 湿度测量范围：0～100%RH，最大误差是±5％RH
* 封装：DFN-6，3mm * 3mm

## 三、软件接口

### SI7006(i2cObj) - 创建SI7006驱动对象
* 函数原型：
> si7006Obj = SI7006(i2cObj)

* 参数说明：  

|参数|类型|必选参数？|说明|
|-----|----|:---:|----|
|i2cObj|I2C|是|调用此函数前需确保i2cObj对象已经处于open状态|

* 返回值：  
SI7006对象成功，返回SI7006对象；SI7006对象创建失败，抛出Exception

* 示例代码： 

```Python
from driver import I2C               # 驱动库
import si7006                        # SI7006温湿度传感器驱动库

# 初始化I2C类型的设备
i2cObj = I2C()
i2cObj.open("si7006")                # 按照board.json中名为"si7006"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象
print("si7006 inited!")

humitureDev = si7006.SI7006(i2cObj)  # 初始化SI7006传感器
```

* 输出：
```
si7006 inited!
```

### getTemperature - 测量温度

* 函数功能：  
量测周围温度并返回测量结果

* 函数原型：
> SI7006.getTemperature()

* 参数说明：  
无

* 返回值：  
成功返回温度测量结果（数据类型：浮点型；单位：摄氏度）；失败抛出Exception

* 示例： 

```Python
from driver import I2C               # 驱动库
import si7006                        # SI7006温湿度传感器驱动库

# 初始化I2C类型的设备
i2cObj = I2C()
i2cObj.open("si7006")                # 按照board.json中名为"si7006"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象

humitureDev = si7006.SI7006(i2cObj)  # 初始化SI7006传感器

temp = humitureDev.getTemperature()
print("temperature is ", temp, "°C")

```

* 输出：
```
temperature is 25.3°C
```

* 函数功能：  
同时量测周围温度和相对湿度并返回测量结果

* 函数原型：

* 示例： 


## 四、接口案例  
此使用实例在board.json中定义了名为si7006的I2C类型的对象。在Python脚本中周期性的获取温湿度测量结果并打印在日志中。

* 代码：
```Python
# board.json配置：
{
    "name": "board-name",
    "version": "1.0.0",
    "io": {
      "si7006": {
        "type": "I2C",
        "port": 1,
        "addrWidth": 7,
        "freq": 400000,
        "mode": "master",
        "devAddr": 64
      }
    },
    "debugLevel": "ERROR",
    "repl": "disable"
}
  
```
```Python
# Python代码
import utime                         # 延时API所在组件
from driver import I2C               # 驱动库
import si7006                        # SI7006温湿度传感器驱动库

# 初始化I2C类型的设备
i2cObj = I2C()
i2cObj.open("si7006")                # 按照board.json中名为"si7006"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象

humitureDev = si7006.SI7006(i2cObj)  # 初始化SI7006传感器

# 通过温湿度传感器读取温湿度信息
def get_temp_humi():
    temperature = humitureDev.getTemperature()         # 获取温度测量结果
    humidity = humitureDev.getHumidity()               # 获取相对湿度测量结果
    '''
    # 如果需要同时获取温湿度信息，可以呼叫getTempHumidity，实例代码如下:
    humniture = humitureDev.getTempHumidity()          # 获取温湿度传感器测量到的温湿度值
    temperature = humniture[0]                         # get_temp_humidity返回的字典中的第一个值为温度值
    humidity = humniture[1]                            # get_temp_humidity返回的字典中的第二个值为相对湿度值
    '''
    print("The temperature is: %.1f" % temperature)
    print("The humidity is: %d" % humidity)

    return temperature, humidity                        # 返回读取到的温度值和相对湿度值

if __name__ == '__main__':

    while True:
        data = get_temp_humi()                          # 读取温度信息和相对湿度信息
        utime.sleep(1)                                  # 每隔1秒钟进行一次温湿度信息测量和打印

    i2cObj.close()                                      # 关闭I2C设备对象
```

* 输出：
```Python
...
The temperature is 25.3°C
The humidity is 60%H
...
The temperature is 25.3°C
The humidity is 60%H
...

```

## 五、通信协议
# The commands provided by SI7006

主控芯片和SHT3X-DIS传感器之间通信所用命令字如下表所示：
|序号|命令字|功能说明|命令字宏定义|
|:-:|:-:|:-|:-|
|1|0xE5|量测相对湿度 - Hold Master Mode|CMDMEAS_REL_HUMIDITY_MASTER_MODE|
|2|0xF5|量测相对湿度 - No Hold Master Mode|CMD_MEAS_REL_HUMIDITY_NO_MASTER_MODE|
|3|0xE3|量测相对湿度 - Hold Master Mode|CMD_MEAS_TEMP_MASTER_MODE|
|4|0xF3|量测相对湿度 - No Hold Master Mode|CMD_MEAS_TEMP_NO_MASTER_MODE|
|5|0xE0|读取上一次温度测量结果|CMD_READ_OLD_TEMP|
|6|0xFE|传感器功能复位|CMD_RESET|
|7|0xFA0F|读取芯片ID - 首字节|CMD_READ_ID_1st|
|9|0xFCC9|读取芯片ID - 末字节|CMD_READ_ID_2nd|
|10|0x84B8|读取Firmware版本|CMD_READ_Firmware_Revision|

实际控制此传感器的流程可参考如下伪代码。 
</br>

* 获取传感器芯片ID信息
```Python
    通过I2C发送CMD_READ_ID_1st
    等待30ms
    ID_LOW = 通过I2C发起读操作（4字节）

    通过I2C发送CMD_READ_ID_2nd
    等待30ms
    ID_HIGH = 通过I2C发起读操作（4字节）

    将两次读操作读到的芯片ID信息组合成实际的芯片ID（ID_HIGH << 32 | ID_LOW）
```

* 获取传感器Firmware版本信息
```Python
    通过I2C发送CMD_READ_Firmware_Revision
    等待30ms
    通过I2C发起读操作（1字节）
```

* 测量温度并获取测量结果
```Python
    发送I2C命令CMD_MEAS_TEMP_NO_MASTER_MODE
    等待30ms
    通过I2C发起读操作（2字节，data[0]和data[1]）

    计算实际温度值
```
实际温度值 = (175.72 * ((data[0] << 8) | data[1])) / 65536.0 - 46.85

* 测量相对湿度并获取测量结果
```Python
    发送I2C命令CMD_MEAS_REL_HUMIDITY_NO_MASTER_MODE
    等待30ms
    通过I2C发起读操作（2字节，data[0]和data[1]）

    计算实际相对湿度值
```
实际相对湿度值 = (125.0 * ((data[0] << 8) | data[1])) / 65535.0 - 6.0
