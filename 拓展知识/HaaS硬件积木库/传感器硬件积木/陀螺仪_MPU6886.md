### MPU6886(i2cObj) - 创建MPU6886驱动对象
* 函数原型：
> mpu6886Obj = MPU6886(i2cObj)

* 参数说明：

|参数|类型|必选参数？|说明|
|-----|----|:---:|----|
|i2cObj|I2C|是|调用此函数前需确保i2cObj对象已经处于open状态|

* 返回值：
MPU6886对象成功，返回MPU6886对象；MPU6886对象创建失败，抛出Exception

* 示例代码：

```Python
from driver import I2C               # 驱动库
import mpu6886                        # MPU6886温湿度传感器驱动库

# 初始化I2C类型的设备
i2cObj = I2C()
i2cObj.open("mpu6886")                # 按照board.json中名为"mpu6886"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象
print("mpu6886 inited!")

mpu6886Dev = mpu6886.MPU6886(i2cObj)  # 初始化MPU6886传感器
```

* 输出：
```log
mpu6886 inited!
```

### getTemperature - 测量温度

* 函数功能：
量测周围温度并返回测量结果

* 函数原型：
> MPU6886.getTemperature()

* 参数说明：
无

* 返回值：
成功返回温度测量结果（数据类型：浮点型；单位：摄氏度）；失败抛出Exception

* 示例：

```Python
from driver import I2C               # 驱动库
import mpu6886                        # MPU6886温湿度传感器驱动库

# 初始化I2C类型的设备
i2cObj = I2C()
i2cObj.open("mpu6886")                # 按照board.json中名为"mpu6886"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象

mpu6886Dev = mpu6886.MPU6886(i2cObj)  # 初始化MPU6886传感器

temp = mpu6886Dev.getTemperature()
print("temperature is ", temp, "°C")

```

* 输出：
```log
temperature is 28.9°C
```

### getAcceleration - 获取加速度值

* 函数功能：
获取传感器的加速度值

* 函数原型：
> MPU6886.getAcceleration()

* 参数说明：
无

* 返回值：
成功返回传感器加速度值的结果（数据类型：浮点；单位：mg）；失败抛出Exception

* 示例：

```Python
from driver import I2C               # 驱动库

# 初始化I2C类型的设备
i2cObj = I2C()

mpu6886Dev = mpu6886.MPU6886(i2cObj)  # 初始化MPU6886传感器

acc = mpu6886Dev.getAcceleration()
print(acc)

```

* 输出：
```log
(-0.4692635, -0.01197101, 10.53688)
```

## 四、接口案例
此使用实例在board.json中定义了名为mpu6886的I2C类型的对象。在Python脚本中周期性的加速度、陀螺仪以及温度结果并打印在日志中。

* 代码：
```Python
# board.json配置：
{
    "name": "board-name",
    "version": "1.0.0",
    "io": {
      "mpu6886": {
        "type": "I2C",
        "port": 0,
        "addrWidth": 7,
        "freq": 400000,
        "mode": "master",
        "devAddr": 104
      }
    },
    "debugLevel": "ERROR",
    "repl": "disable"
  }

```

```Python
# Python代码

import utime   # 延时函数在uti
import utime                         # 延时API所在组件
from driver import I2C               # 驱动库
import mpu6886

i2cObj = None
mpu6886Dev = None

# 通过温湿度传感器读取温湿度信息
def get_mpu6886_data():

    acc = mpu6886Dev.getAcceleration
    gyro = mpu6886Dev.getGyro
    temp = mpu6886Dev.getTemperature
    print(acc)
    print(gyro)
    print("temp: ",temp)
    return acc, gyro , temp                     # 返回读取到的温度值和相对湿度值

if __name__ == '__main__':
    # 硬件初始化
    i2cObj = I2C()
    i2cObj.open("mpu6886")                 # 按照board.json中名为"mpu6886"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象
    print("mpu6886 inited!")
    mpu6886Dev = mpu6886.MPU6886(i2cObj)   # 初始化MPU6886传感器
    while True:
        data = get_mpu6886_data()                          # 读取传感器信息值
        utime.sleep(1)                                   # 每隔1秒钟进行一次传感器信息值的获取以及打印
    i2cObj.close()                                      # 关闭I2C设备对象

```
