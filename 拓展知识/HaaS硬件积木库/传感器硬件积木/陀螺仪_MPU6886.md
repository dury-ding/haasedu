# 陀螺仪MPU6886模块

## 一、产品简介
MPU6886是一款6轴运动传感器，集成了3轴陀螺仪和3轴加速度计。具有1KB FIFO缓冲区，可以降低串行总线接口上的通信量，并通过允许系统处理器突发读取传感器数据，然后进入低功耗模式来降低功耗。功能上还包括片上16位ADC、可编程数字滤波器、嵌入式温度传感器和可编程中断。具有400KHz的I2C和10MHz的SPI两种串行接口通信方式，支持20000g冲击可靠性和稳定性，保证了最佳运动性能。主要应用在智能手机、平板电脑、可穿戴设备、机顶盒、3D遥控器和游戏控制器等产品中。


## 二、技术参数
* 工作电压：1.71v~3.45v<br>
* 睡眠电流：<=10uA@25°C<br>
* 工作电流(Low-Noise Mode)：<br>
  (1) 6轴(陀螺仪+加速度)：<=3mA <br>
  (2) 3轴(加速度)：<=370uA <br>
  (3) 3轴(陀螺仪)：<=2.8mA <br>
* 工作温度：-40°C～+85°C<br>
* 通信接口：400KHz I2C或10MHz SPI<br>
* 三轴陀螺仪可编程范围：±250dps、±500dps、±1000dps和±2000dps<br>
* 陀螺仪灵敏度误差：±1%<br>
* 陀螺仪噪声：4mdps/√Hz<br>
* 三轴加速度计可编程范围：±2g、±4g、±8g和±16g<br>
* 加速度计噪声：100μg/√Hz<br>
* 片上16位ADC和可编程滤波器<br>
* 用户可编程中断<br>
* 封装尺寸：LGA 3mm * 3mm * 0.75mm<br>
* 符合RoHS和绿色标准<br>

### MPU6886(i2cObj) - 创建MPU6886驱动对象
* 函数原型：
> mpu6886Obj = MPU6886(i2cObj)

* 参数说明：

|参数|类型|必选参数？|说明|
|-----|----|:---:|----|
|i2cObj|I2C|是|调用此函数前需确保i2cObj对象已经处于open状态|

* 返回值：
MPU6886对象成功，返回MPU6886对象；MPU6886对象创建失败，抛出Exception

* 示例代码：

```Python
from driver import I2C               # 驱动库
import mpu6886                        # MPU6886温湿度传感器驱动库

# 初始化I2C类型的设备
i2cObj = I2C()
i2cObj.open("mpu6886")                # 按照board.json中名为"mpu6886"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象
print("mpu6886 inited!")

mpu6886Dev = mpu6886.MPU6886(i2cObj)  # 初始化MPU6886传感器
```

* 输出：
```log
mpu6886 inited!
```

## 四、接口案例

```Python
    "io": {
      "mpu6886": {
        "type": "I2C",
        "port": 0,
        "addrWidth": 7,
        "freq": 400000,
        "mode": "master",
        "devAddr": 104
      }
    },
    "debugLevel": "ERROR",
    "repl": "disable"
  }

```

```Python
# Python代码

import utime                         # 延时API所在组件
from driver import I2C               # 驱动库
import mpu6886

i2cObj = None
mpu6886Dev = None

# 通过温湿度传感器读取温湿度信息
def get_mpu6886_data():

    acc = mpu6886Dev.getAcceleration
    gyro = mpu6886Dev.getGyro
    temp = mpu6886Dev.getTemperature
    print(acc)
    print(gyro)
    print("temp: ",temp)
    return acc, gyro , temp                     # 返回读取到的温度值和相对湿度值

if __name__ == '__main__':
    # 硬件初始化
    i2cObj = I2C()
    i2cObj.open("mpu6886")                 # 按照board.json中名为"mpu6886"的设备节点的配置参数（主设备I2C端口号，从设备地址，总线频率等）初始化I2C类型设备对象
    print("mpu6886 inited!")

    while True:
        data = get_mpu6886_data()                          # 读取传感器信息值
```

## 五、工作原理
下图是MPU6886传感器的功能框图，可以看到MPU6886主要有三轴加速度和三轴陀螺仪功能组成，并由16位ADC转换成数字信号，通过I2C或者SPI总线接口和主控芯片通信，其中I2C速率是400KHz，通过SA0管脚的高低电平区分地址，当SA0是低电平时，I2C地址是0x68；当SA0是高电平时，I2C地址是0x69，而SPI的速率是10MHz，且以四线模式运行。

### 1、三轴MEMS陀螺仪
MPU6886由三个独立的振动MEMS速率陀螺仪组成，可以检测X、Y和Z轴的旋转。当陀螺仪绕任何一个感测轴旋转时，科里奥利效应会引起电容式传感器检测到振动，获取的信息被放大、解调和滤波，以产生与角速率成比例的电压。然后使用单个片上16位ADC（模数转换器）对该电压进行数字化，以对每个轴进行采样。陀螺仪传感器的满标度范围可通过数字编程设定为±250、±500、±1000或±2000度/秒（dps）。ADC采样率也可编程，从每秒8000个采样率降至每秒3.9个采样率，用户可选择的低通滤波器可实现广泛的截止频率。

### 2、三轴MEMS加速度计
MPU6886的三轴加速计对每个轴使用单独校准。沿特定轴的加速度会在相应的校准质量上产生位移，而电容传感器会对位移进行差分检测。MPU6886的结构降低了加速计对制造变化和热漂移的敏感性。当设备放置在平面上时，其X轴和Y轴上的测量值为0g，Z轴上的测量值为+1g。加速计的比例系数在工厂进行校准，名义上与电压无关。每个传感器都有一个专用的ADC，用于提供数字输出。
