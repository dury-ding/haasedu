## 三、软件接口
<br>

### BUZZER(pwmObj) - 创建蜂鸣器驱动对象
<br>

* 函数原型

> buzzerObj = BUZZER(pwmObj)

* 参数说明

参数|类型|必选参数？|说明|
|:-:|:-:|:-:|:-|
|buzzerObj|PWM|是|调用此函数前需确保buzzerObj对象已经处于open状态|

* 返回值

> BUZZER对象成功，返回BUZZER对象；BUZZER对象创建失败，抛出Exception

* 示例代码
```python
from driver import PWM
from time import sleep
import buzzer

pwmObj = PWM()
pwmObj.open("buzzer")
print("buzzer inited!")

obj_buzzer = buzzer.BUZZER(pwmObj)
```

* 输出
```python
buzzer inited!
```
</br>

### setOptionDuty(data) - 设置蜂鸣器的声音
<br>

* 函数功能：

> 设置蜂鸣器的声音

* 函数原型： 

> BUZZER.setOptionDuty(data)

* 参数说明：

参数|类型|必选参数？|说明|
|:-:|:-:|:-:|:-|
| data|json|是|例如：data = {'freq':2000, 'duty': 10 } <br>freq - pwm频率 <br> duty - 0-100(占空比)|

* 返回值：

> 无

* 示例：

```python
from driver import PWM
from time import sleep
import buzzer

pwmObj = PWM()
pwmObj.open("buzzer")
print("buzzer inited!")

obj_buzzer = buzzer.BUZZER(pwmObj)
data_r = {'freq':2000, 'duty': 10 } 
obj_buzzer.setOptionDuty(data_r)
```

* 输出
```python
buzzer inited!
```

## 四、接口案例

此使用实例在board.json中定义了名为DCMotor的GPIO类型的对象。在Python脚本中执行一次开始转动和停止转动的动作并打印在日志中。

* 案例代码
```python
{
    "name": "board-name",
    "version": "1.0.0",
    "io": {
        "dcmotor": {
            "type": "GPIO",
            "port": 2,
            "dir": "output",
            "pull": "pulldown"
        }
    }
}
```

```python
from driver import PWM
from time import sleep
import buzzer

obj_buzzer = None
# init function
def makerobo_setup():
    global obj_buzzer
    pwmObj = PWM()
    pwmObj.open("buzzer")
    print("buzzer inited!")

    obj_buzzer = buzzer.BUZZER(pwmObj)
    # define init freq and duty
    data_r = {'freq':2000, 'duty': 0 } 
    obj_buzzer.setOptionDuty(data_r)

# loop to change pwm output
def makerobo_loop():
    R_val = 10
    while (R_val <= 100):
        print("duty = ", R_val)
        data_r = {'freq':2000, 'duty': R_val } 
        obj_buzzer.setOptionDuty(data_r)
        sleep(1) 
        R_val = R_val+10

# main entry
if __name__ == "__main__":
    makerobo_setup()
    makerobo_loop()
```

* 输出
```python
buzzer inited!
```
