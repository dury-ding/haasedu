# 蜂鸣器模块

## 一、产品简介
蜂鸣器是一种一体化结构的电子讯响器，采用直流电压供电，广泛应用于计算机、打印机、复印机、报警器、电子玩具、汽车电子设备、电话机、定时器等电子产品中作发声器件。蜂鸣器主要分为压电式蜂鸣器和电磁式蜂鸣器两种类型。此有源蜂鸣器模块采用压电式，高电平触发原理，即当I/O口输入高电平时，蜂鸣器发声，具体外观接口如下图：

* 工作温度：-20~85℃<br>
* 模块采用S8050三极管驱动<br>
* 接口方式: GPIO<br>

## 三、软件接口
<br>

### BUZZER(pwmObj) - 创建蜂鸣器驱动对象
<br>

* 函数原型

> buzzerObj = BUZZER(pwmObj)

* 参数说明

参数|类型|必选参数？|说明|
|:-:|:-:|:-:|:-|
|buzzerObj|PWM|是|调用此函数前需确保buzzerObj对象已经处于open状态|

* 返回值

> BUZZER对象成功，返回BUZZER对象；BUZZER对象创建失败，抛出Exception

* 示例代码
```python
from driver import PWM
from time import sleep
import buzzer

pwmObj = PWM()
pwmObj.open("buzzer")
print("buzzer inited!")

obj_buzzer = buzzer.BUZZER(pwmObj)
```

* 输出
```python
buzzer inited!
```
</br>

### setOptionDuty(data) - 设置蜂鸣器的声音
<br>

* 函数功能：

> 设置蜂鸣器的声音

* 函数原型： 

> BUZZER.setOptionDuty(data)

* 参数说明：

参数|类型|必选参数？|说明|
|:-:|:-:|:-:|:-|
| data|json|是|例如：data = {'freq':2000, 'duty': 10 } <br>freq - pwm频率 <br> duty - 0-100(占空比)|

* 返回值：

> 无

* 示例：

```python
from driver import PWM
from time import sleep
import buzzer

pwmObj = PWM()
pwmObj.open("buzzer")
print("buzzer inited!")

obj_buzzer = buzzer.BUZZER(pwmObj)
data_r = {'freq':2000, 'duty': 10 } 
obj_buzzer.setOptionDuty(data_r)
```

* 输出
```python
buzzer inited!
```

## 四、接口案例

此使用实例在board.json中定义了名为DCMotor的GPIO类型的对象。在Python脚本中执行一次开始转动和停止转动的动作并打印在日志中。

* 案例代码
```python
{
    "name": "board-name",
    "version": "1.0.0",
    "io": {
        "dcmotor": {
            "type": "GPIO",
            "port": 2,
            "dir": "output",
            "pull": "pulldown"
        }
    }
}
```

```python
from driver import PWM
from time import sleep
import buzzer

obj_buzzer = None
# init function
def makerobo_setup():
    global obj_buzzer
    pwmObj = PWM()
    pwmObj.open("buzzer")
    print("buzzer inited!")

    obj_buzzer = buzzer.BUZZER(pwmObj)
    # define init freq and duty
    data_r = {'freq':2000, 'duty': 0 } 
    obj_buzzer.setOptionDuty(data_r)

# loop to change pwm output
def makerobo_loop():
    R_val = 10
    while (R_val <= 100):
        print("duty = ", R_val)
        data_r = {'freq':2000, 'duty': R_val } 
        obj_buzzer.setOptionDuty(data_r)
        sleep(1) 
        R_val = R_val+10

# main entry
if __name__ == "__main__":
    makerobo_setup()
    makerobo_loop()
```

* 输出
```python
buzzer inited!
```

## 五、工作原理
有源蜂鸣器是靠压电效应的原理来发声的，压电材料，一般常见的是各种压电陶瓷。 这种材料的特别之处在于，当电压作用于压电材料时，就会随电压和频率的变化产生机械变形。另一方面，当振动压电陶瓷时，则会产生电荷。就是说这种材料能把机械变形和电荷相互转化，压电式蜂鸣器里面的起振片，就是一种压电陶瓷。如上所述，要让它振动，除了压电陶瓷本身，还需要适当大小和频率变化的电压作用于压电陶瓷。有源蜂鸣器内部带有多谐振荡器，可以产生 1.5—2.5kHZ 的电压信号。 由此有源蜂鸣器才能发声。
