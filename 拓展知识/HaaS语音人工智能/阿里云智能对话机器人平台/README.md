# 什么是智能对话机器人
&emsp;&emsp;
阿里云智能对话机器人（原云小蜜）依托阿里云AI技术，为企业提供一体化对话机器人服务，帮助企业构建新一代全时段智能交互系统，精准理解用户意图，支持界面化流程配置、自定义三方业务集成等功能，降本增效，广泛适用于智能客服问答、智能办公助理、售前业务咨询等场景。

<br>

## 多模态智能问答，满足不同场景问答需求
&emsp;&emsp;
支持FAQ问答、任务式问答、文档问答、英文问答能力，满足多样化问答需求。

&emsp;&emsp;
FAQ问答：可支持FAQ类的问答能力，通过简单的QA问答对录入，精准理解用户意图，快速回复用户问题。

&emsp;&emsp;
任务式问答：界面化多轮交互编辑器，支持自定义对话流程，可通过服务集成轻松集成三方业务接口，实现问答业务对接。

&emsp;&emsp;
文档问答：自动化解析非结构化文档，自动回复文档中的知识，免于知识梳理和录入，低成本构建文档问答体系。

&emsp;&emsp;
英文问答：效果显著的英文问答模型，支持英文问答，可通过选配旗舰版实现双语问答功能。

<br>

## 在线运维优化体系，提升系统智能化水平
&emsp;&emsp;
通过多维数据分析及在线数据标注提升系统智能化水平。

&emsp;&emsp;
数据分析：提供会话数据分析看板，支持高频问答数据统计，支持会话记录查询分析。

&emsp;&emsp;
问答训练：支持在线问答标注训练功能，无答案问题、未命中问题可一键标注添加至问答模块， 实时调优提升知识覆盖度。

&emsp;&emsp;
权限管控：用户权限分级管控，支持知识审核功能，降低知识数据风险，问答内容高度可控。

<br>

## 灵活的产品形态，动态满足系统集成部署需求
&emsp;&emsp;
支持多种管控API接口调用，易于集成，满足多种可用性需求

&emsp;&emsp;
API集成：支持管控层API集成，可通过API实现知识、数据的增删改，灵活集成至自有产品体系中。

&emsp;&emsp;
多视角多实例：在不同的渠道可以设置不同的视角，针对不同视角提供差异化的回复，支持多机器人实例部署，满足多样化场景需求。

&emsp;&emsp;
弹性扩容：动态弹性扩容，自由升降配调用量，动态适配不同业务发展阶段。
