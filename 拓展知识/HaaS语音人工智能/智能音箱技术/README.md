# 智能音箱技术
## 智能音箱的发展现状
&emsp;&emsp;
在传统音箱基础上，增加了语音识别等智能化功能的音箱即为智能音箱。智能音箱的功能主要体现在两方面：
* 技术上表现在可Wi-Fi连接，实现人机语音交互。
* 功能上表现在能够提供有声读物、广播、音乐等内容服务，信息查询、网上购物等互联网服务，以及作为现阶段智能家居的入口提供相应的控制能力。随着人工智能等技术的迅速发展以及智能家居产品种类不断丰富，智能音箱迎来发展机遇，未来发展趋势逐渐清晰。

<br>

### 核心技术提升促进智能音箱发展
&emsp;&emsp;
人工智能产业的蓬勃发展为智能音箱产业提供了重要的技术保障，先进的AI技术可极大增强智能音箱的可靠性，促进了该产业的发展。除了AI技术的进步，其余智能音箱相关的产业技术也不断取得长远发展。
* 智能语音核心技术取得突破，让语音执行命令更准确；
* 语音芯片由通用转为专用，各生产商研发专用芯片的力度较大，成就显著；
* 麦克风阵列技术逐渐成熟，逐渐实现远场语音交互的覆盖；
* 云平台服务功能完善，安全性及可靠性增强，满足消费者需求。

&emsp;&emsp;
此外，智能音箱生产工厂的供给能力提高，产业链合作加强，生产效率不断提高。这些都为智能音箱产业的发展奠定了基础。

<br>

### 智能家居带动智能音箱发展
&emsp;&emsp;
近年来智能家居逐渐走入千家万户，产业市场规模不断增长。智能家居产品种类繁多，很多家庭有着智能门锁、扫地机器人、智能电视、智能洗衣机、智能电冰箱等不同类型的智能家居产品，这些产品需要一个交互性好的控制中心，此时智能音箱脱颖而出。

<br>

### 屏幕音箱成为品牌竞争下一个主战场，教育市场增量机会可期
&emsp;&emsp;
目前，智能音箱的市场主要以简单的语音交互和播放音频为主，而在疫情期间，在线教育的刚需，这为智能音箱开辟了新的市场。疫情期间，小孩在家上课常态化，这让带屏音箱使用场景的粘性大幅增加，给带屏音箱的发展带来了极大的空间，也让智能音箱的品牌以产品为载体，加大了教育资源的投入，能够很好的补上早教、补习等需求缺口。据奥维云网(AVC)线上监测数据显示，2019年屏幕音箱成为主流，市场份额达到了14.2%，到2020年上半年，屏幕音箱的份额进一步提高，屏幕音箱份额达到19.8%，其中2020年1月、2月以及6月份额均突破20%大关。

<br>

## 智能音箱技术流程

<div align="center">

</div>

&emsp;&emsp;
智能音箱的基本交互流程如上图所示：

&emsp;&emsp;
1）用户通过自然语言向音箱提出问题或服务要求

&emsp;&emsp;
2）音箱拾取用户声音（音箱本地完成）并分析（一般在服务器端完成）

&emsp;&emsp;
3）音箱通过语言播报（音箱端）和APP推送（关联的手机等）对用户的要求进行反馈。

&emsp;&emsp;
在硬件层面上，智能音箱主要由主控板，麦克风，扬声器，蓝牙Wi-Fi等组成，算法层面上，智能音箱基本使用了全套的语音方面的技术。
