# 算法调优

## 课程目标

&emsp;&emsp;
通过学习本章，使学生了解神经网络模型调优的重要性，通过一个案例来掌握该如何调整超参数以及一些常用的优化手段。学习和理解常见的优化策略，了解这些算法的原理和优缺点，体验算法是如何在不断地调整超参数以达到提升模型准确率的目标。

&emsp;&emsp;
在学习算法调优理论后，再了解神经结构搜索、量化压缩、模型压缩等时下流行的模型优化方法，掌握可以从哪些方面来优化模型。最后介绍了阿里云的PAI-Blade通用推理优化框架，了解PAI-Blade是如何应用了上述技术来实现模型的最优推理性能。

## 教学安排

- 教学时长（理论1学时+实验4课时）
- 本章知识点：了解神经结构搜索、量化压缩、模型压缩等算法调优方法，介绍阿里云PAI-Blade优化框架
- 本章重点：理解量化压缩和模型压缩的过程
- 本章难点：掌握如何实现模型的量化与压缩
