# 机器视觉概论

## 课程目标
&emsp;&emsp;
作为概论课，通过本章课程主要向学生介绍计算机视觉学科的发展历史，特色以及一些基本概念。让学生通过课程对机器视觉的发展历程与现状，相关理论与算法有一个基本的了解与认识。然后在此基础上将着重介绍一些数字图像处理有关基础知识以及常用的一些机器视觉相关算法模型，让学生了解利用计算机做一些机器视觉任务背后所经历的过程以及涉及的相关技术。

## 教学安排

- 教学时长（理论2学时）
- 本章知识点：机器视觉概念、视觉理论的发展、机器视觉系统的构成、机器视觉与相关领域、机器视觉的应用。
- 本章重点：掌握机器视觉的概念、理解机器视觉理论。
- 本章难点：Marr的机器视觉理论。
