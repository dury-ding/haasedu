# 智慧城市

&emsp;&emsp;
智慧城市是指利用各种信息技术或创新概念，将城市的系统和服务打通、集成，以提升资源运用的效率，优化城市管理和服务以及改善市民生活质量。

&emsp;&emsp;
从技术的角度来看，智慧城市则是通过以移动技术为代表的物联网技术、云计算技术等新一代信息技术实现全面透彻的自动感知、泛在互联、普适计算与融合应用。在智慧城市建设的过程中物联网技术作为“自动感知和泛在互联”的基础设施，起着至关重要的作用，尤其是在可能出现类极端灾害天气及其它突发紧急事件的情况下可以提前进行预警起到保护人民生命财产安全的目的。
