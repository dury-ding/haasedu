# 花卉养植之自动温湿度调节

&emsp;&emsp;
[花卉养植之温湿度数据上云](../2-温湿度数据上云/README.md)中完成了茶花生长环境的温湿度测量及上报物联网平台的部分，这节课程则主要完成自动温湿度调节的功能。主要包含以下两部分：
1. 自动温度调节
* 在环境温度超过28度的时候开启空调
* 在环境温度低于26度的时候关闭空调

2. 自动湿度调节
* 在环境湿度超过70%的时候关闭加湿器
* 在环境湿度低于50%的时候开启加湿器

## 功能拆解

&emsp;&emsp;
本节课功能主要分为2部分：
1. 控制空调或加湿器
2. 温度或湿度到阈值之后执行空调或加湿器的打开或者关闭

### **控制空调或加湿器**
&emsp;&emsp;
控制空调或加湿器的部分一般会通过控制电路控制继电器从而间接来控制空调或加湿器的电路开关。通过继电器控制空调开关的示意图如下所示，加湿器是相同的原理。
* 当继电器的控制电路A和B两端没有电压的情况，被控制电路处于断开状态，空调被关闭
* 当继电器的控制电路A和B两端加上电压的情况，被控制电路处于打开状态，空调被打开

<div align="center">
<img src=./../../../图片/3_花卉养植_继电器控制空调开关.png width=40%/>
</div>

&emsp;&emsp;
实际在控制继电器的时候使用设备的GPIO端口控制继电器的控制电路即可，如下图所示。

<div align="center">
<img src=./../../../图片/3_花卉养植_GPIO控制继电器示意图.png width=40%/>
</div>

&emsp;&emsp;
当微处理器的GPIO输出0（低电平）的时候，A和B之间没有电压差，所以C和D之间是断开的；当微处理器的GPIO输出1（高电平）的时候，A和B之间有电压差，就会让C和D之间导通。

&emsp;&emsp;
为了能比较直观的看到实验现象我们用两颗LED来代替继电器和微处理器的GPIO相连。这样在需要打开空调或加湿器的时候就可以看到对应的LED亮起，在关闭空调或加湿器的时候就 可以看到对应的LED灭掉。

&emsp;&emsp;
经过上面的分析可以看出，在温湿度数据上云的基础上，硬件方面我们还需要增加两颗LED分别接到硬件的两个GPIO引脚上。

&emsp;&emsp;
因为需要新增硬件，并且通过物联网平台来控制此硬件的行为，所以需要在云端产品的物模型中增加属性，并在设备上接收并解析云端控制属性的指令来完成实际设备的控制。

#### **云端物模型**
&emsp;&emsp;
在此产品的物模型中新增两个bool类型的属性，命名为"airconditioner"和"humidifier"分别用来控制空调和加湿器。
* 当需要打开空调时，云端将“airconditioner”的属性值设置为True；需要关闭空调时，将其设置为False。
* 当需要打开加湿器时，云端将“humidifier”的属性值设置为True；需要关闭空调时，将其设置为False。

## 实验现象

* 在温度高于阈值时，可以看到日志中出现"打开空调"的字样，伴随着蓝色LED灯亮起
* 在温度低于阈值之后 ，可以看到日志中出现“关闭空调”的字样，伴随着蓝色LED灯熄灭

* 在湿度低于阈值时，可以看到日志中出现"打开加湿器"的字样，伴随着绿色LED灯亮起
* 在湿度高于阈值时，可以看到日志中出现"关闭加湿器"的字样，伴随着绿色LED灯熄灭

## 课后作业

本节课程的内容只是完成了在温度过高时候开启空调和湿度过低的时候开启加湿器的功能，只是完成了其中的一半调节功能，请读者思考看看如何让这个自动温湿度调节功能更加完善，比如：

* 如何在湿度过高的时候避免茶花生病（高温加上多湿，茶花最容易发生炭疽病和黑斑病）
