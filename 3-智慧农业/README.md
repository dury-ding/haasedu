# 智慧农业
&emsp;&emsp;
第七次人口普查的结果显示全国总人口超过14亿，其中有5亿多的人口居住在农村，过去我们用全球7%的土地养活了全球20%的人口，接下来如何用这7%的土地继续为人们日益增长的物质水平提供更充足的保障从而完成从农业大国向农业强国的转变？智慧农业便是其重要战略途径之一。  

&emsp;&emsp;
智慧农业是指现代科学技术与农业种植相结合，从而实现无人化、自动化、智能化管理。它是农业生产的高级阶段，是集移动互联网、云计算和物联网技术为一体，依托部署在农业生产现场的各种传感节点（环境温湿度、土壤水分、二氧化碳、图像等）和无线通信网络实现农业生产环境的智能感知、智能预警、智能决策、智能分析、专家在线指导，为农业生产提供精准化种植、可视化管理、智能化决策。
